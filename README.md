# FriendsHub

Нативное приложение FriendsHub для компьютеров и мобильных устройств. Оно переносит основные возможности FriendsHub в отдельное приложение и продолжает развиваться.

## Состояние проекта

Нативное приложение продолжает развиваться. Доступность отдельных возможностей зависит от платформы; тестирование на iOS остаётся экспериментальным.

## Установка

Опубликованные сборки можно найти на странице [FriendsHub Releases](https://github.com/SomSomovich/friendshub-apps/releases). Выберите файл для своей платформы и следуйте инструкциям системы.

- **Android:** установите APK из выбранного вами источника. Для выпускаемых Android-сборок используется подпись FriendsHub.
- **iOS:** тестовая IPA не подписывается. Чтобы установить приложение на своё устройство, подпишите сборку собственным ключом разработчика Apple через Xcode. Доступ для iOS остаётся экспериментальным.
- **Windows, macOS и Linux:** скачайте сборку для своей системы и запустите её способом, предусмотренным этой системой.

Если для вашей платформы ещё нет опубликованного файла, сборка пока недоступна.

## Первые шаги

Запустите приложение и войдите в существующий аккаунт FriendsHub либо создайте аккаунт. Для доступа к перепискам, группам и каналам используйте те же учётные данные, что и в других клиентах FriendsHub.
